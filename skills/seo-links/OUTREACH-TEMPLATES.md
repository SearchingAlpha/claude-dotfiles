# Plantillas de outreach

Idioma del prospecto (EN para FL). Corto: 5-7 líneas. Un ask. Sin adjetivos sobre nosotros.
Cada borrador se personaliza con la URL exacta del prospecto y la razón concreta.

## Disclosure fija (va siempre, última línea antes de la firma)

> Full disclosure: I run <brand.name>, <positioning en una frase>. No payment or exchange
> involved — link it only if it's useful to your readers.

## 1 · Inclusión en recurso / lista

```
Subject: One more for your <topic> resources page

Hi <name>,
Your <page title> (<url>) lists <what they list>. One gap I noticed: <specific gap>.
We publish <asset>: <what it is, one line with a number and a date>. <Why it fits their list>.
<asset url>
<disclosure>
<signature>
```

## 2 · Actualización de artículo (dato más actual / recurso roto)

```
Subject: <topic> figure in "<article title>" — a 2026 source

Hi <name>,
In <article url> you cite <old figure / broken link>. As of <month 2026>, <new figure> in
<county/metro> — from <asset>, which we update <cadence>. Method and per-county table here: <asset url>.
Happy to send the raw data if useful.
<disclosure>
<signature>
```

## 3 · Mención en comparación / alternativas

```
Subject: <competitor> alternatives in <metro>

Hi <name>,
Your piece on <competitor / topic> (<url>) covers <what>. For <metro> readers, one option
missing: <brand> — <positioning, honest>. What's different: <one concrete difference: price
transparency, county coverage, calculator…>.
If it fits the comparison, here's the page: <asset url>.
<disclosure>
<signature>
```

## 4 · Cita experta / referencia de apoyo

```
Subject: source for "<claim in their article>"

Hi <name>,
Your article states <claim>. We have <data / methodology> supporting (or nuancing) it for
Florida: <one number + date>. If you want a citable source or a quote, it's here: <asset url>.
<disclosure>
<signature>
```

## Reglas

- Nunca "great post!" ni halagos genéricos. La primera línea demuestra que leíste la página.
- Un solo ask, un solo enlace.
- Si el prospecto es cámara / asociación / gobierno: pregunta por su proceso (membresía,
  directorio) antes de pedir el enlace.
- Seguimiento: uno, a los 10 días, dos líneas. Después, `status: descartado`.
